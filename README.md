# Detección de Objetos en Tiempo Real 🎥

Una aplicación web que utiliza TensorFlow.js y modelos de inteligencia artificial para detectar objetos en tiempo real a través de la cámara web.

## ✨ Características

- 🔍 Detección de objetos en tiempo real usando COCO-SSD
- 📊 Visualización de FPS y contador de objetos detectados
- 📸 Captura de screenshots con las detecciones
- 🎯 Interfaz de usuario moderna y responsive
- 📝 Historial de las últimas 10 detecciones
- ⚡ Efectos visuales mejorados en las detecciones

## 🚀 Requisitos

- Navegador web moderno con soporte para WebGL
- Cámara web funcional
- Conexión a Internet (para cargar los modelos de TensorFlow)

## 💻 Uso

1. Abre el archivo `index.html` en tu navegador
2. Permite el acceso a la cámara web cuando se solicite
3. Espera a que se carguen los modelos de IA
4. Usa los botones de control para:
   - "Iniciar Detección": Comienza la detección en tiempo real
   - "Pausar": Detiene temporalmente la detección
   - "Capturar Imagen": Guarda una imagen con las detecciones actuales

## 🛠️ Tecnologías Utilizadas

- TensorFlow.js
- COCO-SSD (para detección de objetos)
- FaceMesh (para detección facial)
- HTML5 Canvas
- JavaScript moderno

## 📝 Notas

- La aplicación mantiene un historial de las últimas 10 detecciones
- Los FPS pueden variar según el hardware y el navegador
- Las capturas de pantalla se guardan automáticamente en tu carpeta de descargas
